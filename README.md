## 🧩 Description

This repository collects exercises and projects developed during my study path. Each project is built using core principles of Web Development, including:

* HTML5 & Semantic Web
* CSS3 & Responsive Design
* JavaScript (ES6+) & DOM Manipulation
* Client-Server Architecture
* Asynchronous Programming (AJAX/Fetch)
